# 🐍 Snake Lab 贪吃蛇实验室

**🎮 立即在线游玩：[https://rainandcr.github.io/snake-lab/](https://rainandcr.github.io/snake-lab/)**

一款现代化贪吃蛇游戏：经典街机体验 + AI 算法实验室 + 本地双人竞技 + 关卡挑战 + 地图编辑器 + 成就系统。
纯前端运行，无需注册登录、无需网络（打开页面后离线也能玩），所有进度保存在你的浏览器 localStorage 中。

> 技术栈：React 18 + TypeScript + Vite + HTML5 Canvas + Web Audio API，109 个 Vitest 自动化测试。

## 快速开始

1. 打开 **[https://rainandcr.github.io/snake-lab/](https://rainandcr.github.io/snake-lab/)**
2. 首页点击 **「开始游戏」** → 选择模式与难度 → 点击 **「开始游戏」**
3. 点击棋盘或按 **空格** → 倒计时 3、2、1 后开局
4. 用 **方向键 / WASD** 控制蛇移动，吃食物得分，撞墙或撞到自己即结束

**推荐配置**：桌面端 Chrome / Edge 浏览器；移动端支持滑动转向与可选虚拟方向键。

## 功能模式详解

### 1. 开始游戏（单人三模式）

| 模式 | 规则 |
|---|---|
| **经典模式** | 标准规则：吃食物 +10 分并长一格，撞墙或撞自己结束 |
| **无尽穿墙** | 四周边界首尾相接，从左边出去会从右边出现（棋盘以虚线边框提示）。该模式须选择有障碍的预设或自定义地图（不含空旷场地） |
| **极速模式** | 初始更快，每得 60 分自动提速一档（有上限），状态栏实时显示 **⚡ 极速等级** 与距下次提速的分数 |

**难度选择**（影响基础速度）：

- 简单：150ms/步 · 普通：120ms/步 · 困难：95ms/步

**场地选择**：默认场地、6 张预设地图（空旷平原/十字障碍/蛇形迷宫/对称竞技场/环形回廊/多房间）、以及你在编辑器中创建的自定义地图。

**随机出生点**：每局出生位置与朝向随机（对战保持左右对称、双方跑道等长），且保证出生点面向方向至少有 8 格安全跑道——不会出现贴墙秒死、来不及反应的情况。

**界面说明**：左上角显示当前分数 / 历史最高分 / 蛇长度 / 累计食物数；右上角状态卡显示游戏状态与速度（格/秒）；限时或目标类玩法会有进度条。**切换标签页或窗口失焦会自动暂停**，返回后需手动点击继续。

**结算**：结束后弹窗显示得分与「再来一局 / 返回菜单」；不同模式 × 不同难度的最高分独立记录。

### 2. AI 算法实验室

观察三种算法在同一棋盘上的搜索与决策行为：

| 控制方式 | 行为 |
|---|---|
| **手动** | 你来操作 |
| **BFS** | 宽度优先搜索，逐层扩散找到食物的最短路径 |
| **A\*** | Manhattan 启发式 + 优先队列，聚焦搜索方向（同局面探索节点数通常远少于 BFS） |
| **安全策略** | A* 找到食物路径后，先模拟吃食物后的未来状态并做洪泛连通性检查；空间不足时追尾自己的尾巴保命，最后手段是选择可达空间最大的方向 |

**可视化图层**（可分别开关）：

- 🔵 已探索格 —— 算法检查过的格子
- 🟣 开放集 —— A* 优先队列中的候选格
- 🟢 规划路径 —— 当前选定的路线

**侧栏面板**：

- **算法指标**：策略原因、探索节点数、路径长度、真实测得计算耗时（每 tick 实时更新）
- **步长滑杆**：60–400ms，随时调整运行速度
- **🎬 慢速演示**：一键切换到 350ms 慢速 + 全图层开启，观察算法思考过程（完成一次演示解锁成就「算法观察者」）
- **⚖️ BFS vs A\***：对当前局面同时跑两个算法，对比探索节点数、路径长度与耗时

> ⚠️ 诚实声明：AI 不能穿墙或穿蛇身；动态蛇身环境下算法需按 tick 重新规划，**没有任何算法能保证永不死亡**。食物不可达或无路可走时，AI 会执行保命移动并在指标面板报告原因。

### 3. 双人对战

同一设备本地对战。三种玩法：

| 玩法 | 规则 |
|---|---|
| **经典竞技** | 活到最后者获胜 |
| **限时积分赛** | 可选 60/120/180 秒，时间到按得分判定，同分为平局 |
| **人机对战** | 对手由 AI 控制，可选 AI 难度：BFS（基础）/ A*（进阶）/ 安全策略（困难） |

**操作**：玩家一 `W A S D`，玩家二 `↑ ← ↓ →`（固定映射，推荐键盘双人；触屏仅控制玩家一并提供虚拟方向键）。

**核心碰撞规则**（游戏内点「规则」按钮可随时查看）：

1. 双方同速同格同步结算，不存在先后手优势
2. 蛇头进入同一格 → 双方同时判负
3. 两蛇头互换位置 → 双方同时判负
4. 撞墙 / 撞自己 / 撞对方身体（含尸体）判负
5. 一方死亡则另一方获胜；同时死亡为平局

**可选道具竞技**（默认关闭，开启后场上随机刷新，上限 2 个）：

| 道具 | 效果 |
|---|---|
| ⚡ 加速 | 自己提速 1.6 倍，持续约 40 tick |
| 🐢 减速 | 自己降速 0.65 倍，方便极限操作 |
| ×2 双倍 | 吃食物得分翻倍 |
| 🛡 护盾 | 抵挡一次致命碰撞；触发时停留在原位，绝不穿入墙壁或蛇身（最多叠 3 层） |

对战战绩（胜/平/负）累计保存在统计中。

### 4. 关卡挑战

**3 大章节 × 15 个官方关卡**，每关有独立地图、速度、目标与三星阈值：

- **第一章 · 新手启程**（1–5）：移动、连续收集、简单障碍、限时赛、综合挑战
- **第二章 · 复杂地形**（6–10）：狭窄通道、多障碍区、迷宫、长蛇生存、中级综合
- **第三章 · 极限挑战**（11–15）：高速、复杂迷宫、高分目标、时间压力、终极综合

**规则**：

- 初始只解锁第 1 关，**通关即解锁下一关**
- 星级按通关时的最终得分评定（每关显示自己的阈值，如第 1 关：50 / 80 / 130 分）
- **历史星级与最佳分数只升不降**，随时可以重玩刷新
- 每关卡片显示地图预览、任务说明、目标与已获星级
- 「自定义关卡」页签独立保存（见编辑器），不影响官方进度

### 5. 地图编辑器

**工具栏**：画笔（墙壁）、橡皮、单人出生点、P1/P2 出生点、食物区（限制食物只在这些格子生成，再点一次取消）。支持点击与拖动绘制，Ctrl+Z / Ctrl+Y 撤销重做（最多 50 步），也可用工具栏按钮。

**创建**：右上角可新建 16×16 / 24×24 / 32×32 空白地图；「穿墙模式」开关让这张地图使用无尽规则。

**保存与校验**：保存时自动校验出生点合法性、连通性（可达空间占比）与食物生成空间，不合法会给出具体错误提示；6 张预设地图只读，「复制编辑」后可修改。

**导入 / 导出**：

- 导出为 `.json` 文件（含 `schemaVersion: 1` 结构版本）
- 导入时校验文件类型、尺寸上限、坐标合法性，**不执行文件中任何代码**，失败给出友好错误

**试玩**：一键以单人或双人模式试玩当前草稿；**创建自定义关卡**：基于当前地图设置目标分数、时间限制与速度，保存后出现在「关卡挑战 → 自定义关卡」页签。

> 基于自定义地图完成一局游戏会累计「地图探险家」成就（需 5 张不同地图）；保存新地图累计「创造大师」（同一张图重复保存不重复计数）。

### 6. 成就中心

**20 个成就**，6 大分类，配置驱动 + 事件驱动解锁，解锁瞬间弹出通知动画：

| 分类 | 成就 |
|---|---|
| 成长 | 初次启程（完成第一局）· 贪吃新手（累计 10 食物）· 美食达人（100）· 贪吃大师（1000） |
| 分数 | 崭露头角（人工单局 100 分）· 百尺竿头（500）· 高分传奇（1000） |
| 对战 | 初次交锋（第一场对战）· 竞技新星（5 胜）· 竞技大师（20 胜） |
| AI | 算法初体验（首次用 BFS）· 启发式探索（首次用 A*）· 算法观察者（完成一次可视化演示） |
| 创造 | 地图设计师（保存首张地图）· 创造大师（创建 10 张）· 地图探险家（玩过 5 张不同自定义地图） |
| 关卡 | 第一颗星 · 勇往直前（通关 5 关）· 挑战大师（通关 15 关）· 完美主义者（15 关全三星） |

> 分数类成就**只统计人工操作局**——AI 刷分与对战得分不会污染人工成就。

### 7. 游戏统计

- 总览卡片：总游玩局数、累计食物、累计得分、游玩时长、对战胜负
- 单人模式最高分表（经典/无尽/极速 × 简单/普通/困难，仅人工操作）
- 最近 10 局记录（模式、分数、食物、时长、结果、时间）
- 「清除统计数据」需二次确认

### 8. 设置

- **主题模式**：跟随系统（自动切换深浅色，默认）/ 深色 / 浅色；页面右上角可快捷三态切换
- **主题外观**：霓虹科技（深蓝底+霓虹绿）/ 极简浅色 / 经典像素，同步改变棋盘与 UI
- **声音**：音效开关与音量调节（首次点击页面后自动启用音频，遵守浏览器自动播放策略）
- **操作**：虚拟方向键开关（触屏备用方案）
- **数据管理**：存储占用显示；**导出备份**（JSON 文件）；**导入备份**（逐键校验恢复，失败键跳过）；**清除全部数据**（二次确认，删除统计/成就/地图/关卡进度/设置）

## 数据存档说明

- 所有数据保存在浏览器 `localStorage`，键名 `snakelab.*`，带版本号与迁移机制
- 模块化分键存储：设置 / 统计 / 成就 / 地图 / 关卡进度 / 自定义关卡
- 损坏数据自动回退默认值，不会导致游戏崩溃；**不同浏览器、隐私模式之间数据不互通**
- 建议定期在「设置 → 数据管理」导出 JSON 备份（清理浏览器数据前务必导出）
- 旧版本存档升级时尽可能保留已识别的字段

## 常见问题

**Q: 打开页面没声音？**
浏览器要求首次交互后才能播放音频，点击任意按钮后即正常。检查设置页音效是否开启。

**Q: 切走标签页回来发现暂停了？**
这是有意设计的防误触机制（窗口失焦自动暂停），点击棋盘或按空格继续。

**Q: AI 也会死？**
是的。安全策略已尽可能规避死路（未来空间模拟 + 追尾保命），但动态环境不保证永不死亡，这是寻路问题的固有局限。

**Q: 刷新后进度丢失？**
检查是否使用了无痕/隐私模式（不保留 localStorage）。正常模式下成就、关卡进度、地图都会保留；如需迁移设备请使用备份导出/导入。

**Q: 手机能玩双人吗？**
单人完全支持触屏；双人强烈推荐键盘（触屏仅控制玩家一，游戏内亦有提示）。

**Q: 棋盘占满了会怎样？**
棋盘被完全占满且无法生成食物时判定为胜利——这是最高荣誉。

## 本地开发

```bash
git clone https://github.com/RainANDCr/snake-lab.git
cd snake-lab
npm install
npm run dev        # 开发服务器 http://localhost:5173
npm run test       # 运行 109 个自动化测试 (Vitest)
npm run test:watch # 监听模式
npm run build      # 类型检查 + 生产构建 → dist/
npm run preview    # 本地预览生产构建
```

**架构速览**：`src/game/core`（统一纯函数规则引擎，所有模式共用）→ `game/{ai,maps,levels,achievements,modes}` → `features`（9 个页面）+ `components`（Canvas 渲染与通用组件）+ `services`（存储/音效/战绩上报）。游戏核心不依赖 React，逻辑与渲染分离，随机数内嵌种子可复现。
