# Snake Lab 贪吃蛇实验室

现代化贪吃蛇游戏：经典街机体验 + AI 算法实验室 + 本地双人竞技 + 关卡挑战 + 地图编辑器 + 成就系统。

## 启动

```bash
npm install
npm run dev        # 开发服务器
npm run test       # 运行测试 (Vitest)
npm run build      # 类型检查 + 生产构建
npm run preview    # 预览生产构建
```

## 技术栈

- React 18 + TypeScript + Vite
- HTML5 Canvas 游戏渲染，React 负责 UI
- Web Audio API 合成音效
- localStorage 版本化本地存档
- Vitest 自动化测试

## 功能

1. **开始游戏**：经典 / 无尽穿墙 / 极速模式，简单/普通/困难三档难度
2. **AI 算法实验室**：BFS、A*、安全策略自动寻路，搜索过程可视化，BFS vs A* 对比
3. **双人对战**：本地同屏经典竞技、限时积分赛、人机对战、可选道具
4. **关卡挑战**：3 大章节 15 个官方关卡，三星评级与解锁进度
5. **地图编辑器**：绘制障碍/出生点/食物区，撤销重做，6 张预设，JSON 导入导出
6. **成就中心**：20 个配置驱动成就，事件解锁与进度追踪
7. **游戏统计**：最高分、最近战绩、对战胜负记录
8. **设置**：三套主题、音效、虚拟方向键、存档备份恢复

纯前端运行，无需服务器与网络，数据保存在浏览器 localStorage。
